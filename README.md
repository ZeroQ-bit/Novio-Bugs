# Novio Bugs

Report bugs related to the Novio Apple TV / tvOS app here.

Use Issues to report:
- playback bugs
- subtitle bugs
- source setup or onboarding bugs
- remote navigation or focus bugs
- metadata or cast display bugs
- profile, watchlist, or continue watching bugs

Do not use this repository for:
- addon-specific outages or problems caused by third-party services
- feature requests without reproduction details
- account or billing questions

When opening a bug report, please include:
- Novio app version
- Apple TV model
- tvOS version
- the installed source or addon involved
- clear steps to reproduce
- screenshots or video if available
